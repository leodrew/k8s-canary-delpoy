## US-101：concurrencyPolicy vs parallelism／completions vs replicas

| ID | 要寫進 guide 的說法 | 依據 | 官方 URL | 來源引文 | 建議寫法 | 使用者確認 |
|---|---|---|---|---|---|---|
| E-015 | `concurrencyPolicy` 管的是「同一個 CronJob 建出來的多個 Job」能不能同時跑 | 官方逐字 | https://kubernetes.io/docs/concepts/workloads/controllers/cron-jobs/ | "It specifies how to treat concurrent executions of a Job that is created by this CronJob." / "Note that concurrency policy only applies to the Jobs created by the same CronJob. If there are multiple CronJobs, their respective Jobs are always allowed to run concurrently." | Part 6.4「`concurrencyPolicy` 怎麼選」之後加小節「三個『幾份』不要搞混」，用三層圖：CronJob →（concurrencyPolicy 管這層）→ Job →（parallelism／completions 管這層）→ Pod；Deployment →（replicas）→ Pod | ✓ |
| E-016 | `parallelism` 是一個 Job 裡同時跑幾個 Pod；未設預設 1；設 0 等於暫停 | 官方逐字 | https://kubernetes.io/docs/concepts/workloads/controllers/job/ | "The requested parallelism (`.spec.parallelism`) can be set to any non-negative value. If it is unspecified, it defaults to 1. If it is specified as 0, then the Job is effectively paused until it is increased." | 同上小節 | ✓ |
| E-017 | `completions` 是要幾個 Pod 成功 Job 才算完成；兩個都不設時都預設 1；Indexed 模式每個 Pod 拿到 0…completions-1 的編號 | 官方逐字 | https://kubernetes.io/docs/concepts/workloads/controllers/job/ | "the Job represents the overall task, and is complete when there are `.spec.completions` successful Pods." / "When both are unset, both are defaulted to 1." / "when using `.spec.completionMode="Indexed"`, each Pod gets a different index in the range 0 to `.spec.completions-1`." | 例子：每晚同步 1000 筆，`completions: 4`、`parallelism: 4`、`completionMode: Indexed`，每個 Pod 用 `JOB_COMPLETION_INDEX` 處理 250 筆。yaml 片段要過 [10]。對照：`concurrencyPolicy: Forbid` 擋的是「昨晚那個 Job 還沒跑完、今晚又來一個」，不是這 4 個 Pod | ✓ |
| E-018 | `replicas` 是 Deployment 期望的 Pod 數，預設 1；Pod 是長駐的，死了 ReplicaSet 會補到這個數量 | 官方逐字 | https://kubernetes.io/docs/reference/kubernetes-api/workload-resources/deployment-v1/ ; https://kubernetes.io/docs/concepts/workloads/controllers/deployment/ | "Number of desired pods. This is a pointer to distinguish between explicit zero and not specified. Defaults to 1." / "ReplicaSet ensures that a specified number of Pod replicas are running at one time" | 對照表一列：replicas 的 Pod「跑完」不算完成、會被重啟；Job 的 Pod 成功退出就是完成。Job 沒有 `replicas` 欄位 | ✓ |
